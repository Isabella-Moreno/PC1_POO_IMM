## Funcionalidades
- **Ejercicio 1 (`Ejercicio1`):** Implementación de la clase `Empleado` combinando acceso `public` para `nombre` y encapsulamiento con getters/setters validados para `salario`, probado mediante `EmpleadoPrueba`.
- **Ejercicio 2 (`Ejercicio2`):** Implementación de `CuentaBancaria` con `tipoCuenta` pública y atributos privados (`numeroCuenta`, `saldo`), evidenciando mediante `CuentaPrueba` el acceso controlado al saldo y el error de compilación al intentar acceder directamente a `numeroCuenta`.
- **Ejercicio 3 (`Ejercicio3`):** Implementación de la clase `Utilidades` con métodos públicos de operaciones matemáticas básicas (`sumar`, `restar`, `multiplicar`, `dividir`), validados en `UtilidadesPrueba`.
